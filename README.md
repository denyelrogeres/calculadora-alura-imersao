# Imersão em Engenharia de Software - Alura & Google AI Studio & Google Antigravity
Esse é o repositório central da Imersão em Engenharia de Software com IA da Alura (de 26/10/2026 à 03/11/2026).

Aqui estão reunidos dois desafios práticos desenvolvidos durante a Imersão. Cada desafio explora uma etapa da formação de um desenvolvedor na era da inteligência artificial: desde lógica fundamental e refatoração com IA até a criação de aplicações web completas com testes automatizados.
